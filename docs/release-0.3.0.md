# PhotoSync 0.3.0-beta — Google и общий архив устройств

Дата сборки: 2026-09-01.

## Что нового

- необязательный вход Google через Android Credential Manager;
- серверная проверка Google ID token для Web OAuth Client ID;
- объединённый архив нескольких телефонов одного Google-аккаунта;
- Google-вход в веб-портал с автоматической связью тех же устройств;
- без Google приложение продолжает работать в приватном пространстве установки;
- выход из Google отвязывает только текущий телефон;
- тёплый семейный интерфейс 0.2 сохранён и дополнен блоком аккаунта;
- APK подписан постоянным release-ключом Bacus Lab.

Сервер хранит только стабильный Google `sub`, подтверждённый email и отображаемое
имя. ID token, Google access token и client secret не сохраняются.

## Важное обновление подписи

Предыдущий публичный 0.2.0-beta был подписан Android debug-ключом. 0.3.0-beta
подписан новым постоянным release-ключом, поэтому Android не установит его поверх
0.2.0-beta. Старую beta нужно удалить, а затем установить 0.3.0-beta. Удаление
стирает локальный ключ установки и создаёт на сервере новое пространство.

Если старый архив не был заранее привязан к Google, новый вход Google не присоединит
его автоматически. Не удаляйте нужные серверные данные: перенос старого пространства
должен выполняться отдельно и с подтверждением владельца.

- 33 серверных integration/unit теста;

этот выпуск не входят.
