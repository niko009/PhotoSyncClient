Войдите с тем же Google-аккаунтом, который подключён в PhotoSync на телефоне. Сервер сам найдёт ваши устройства.

Сервер запущен и готов принимать фотографии с Android. Вход в кабинет откроется после настройки владельцем аккаунта и защищённого соединения. В приложении укажите адрес этого сайта.
